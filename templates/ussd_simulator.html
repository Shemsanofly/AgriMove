Simulating Africa's Talking USSD & SMS

This sandbox simulates the exact request/response lifecycle of the Africa's Talking USSD API and SMS gateway in a real rural environment.

How to use:

  • Step 1: Use the phone keypad on the right to dial *123#.
  • Step 2: Press the green Call button to initiate the USSD session.
  • Step 3: Navigate the menu by entering options in the prompt box and clicking Send.
  • Step 4: Check the SMS Inbox tab on the phone to view notifications generated during actions.
API Format Compatibility

The backend processes payloads matching the Africa's Talking POST payload structure:

{
  "sessionId": "AT_Session_...",
  "serviceCode": "*123#",
  "phoneNumber": "+254700000000",
  "text": "1*2*1"
}

Responses return plain text starting with CON (continue menu) or END (terminate session).
